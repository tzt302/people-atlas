# 风月志 · Private Visit Atlas

一个只为个人使用设计的世界探店地图与私人档案。它不是公开点评、交易或撮合平台；记录和照片默认只保存在当前设备。

Windows 桌面版沿用原有应用 ID 和 GitHub 更新通道。已安装的旧版会在启动时检查新版本、自动下载，并在重启或退出时完成安装。

## 当前功能

- 世界探店热力图：白色表示暂无档案，颜色越深表示记录越多
- 三级地图下钻：世界 → 当地一级行政区（中国省级、美国州级等）→ 建筑级坐标
- 每条档案代表一位人物，可记录照片、昵称、店类型、国家、具体地点、坐标和简介
- 店铺作为人物之间的包含关系：多位人物可以关联同一家店铺，新增时可直接选择已有店铺名称
- 店类型固定为快餐、半、全、按摩、外卖
- 分类页顶部保留档案总数，并集中提供搜索、排序、具体地点、国家、店类型、所属店铺筛选；点击店铺即可查看其中的全部人物
- 详情页支持多次添加独立探店手记，每次保存日期、标题和体验评价
- 五星评价包括综合、沟通、环境、服务和性价比
- 单一的全局“地理 / 分类”切换入口、浅色 / 深色主题、一键平滑回到顶部
- 酒红、深莓、暖金与纸张米色组成的私人旅行手账视觉，并配有原创夜间城市地图插画
- Windows 软件图标采用同套酒红、暖金、“夜”字与弯月视觉
- 旧版本地档案会继续保留，已有店铺关联不会丢失
- 不提供或标注任何地区的法律状态

## 本地运行

这是一个无构建步骤的静态网站。地图和 ES Modules 需要 HTTP，请不要直接双击 `index.html`。

```powershell
python -m http.server 4173
```

然后打开 <http://localhost:4173>。

### 桌面开发与打包

```powershell
pnpm install
pnpm start
pnpm dist
```

## 数据与隐私

档案、评价、手记和上传照片保存在当前浏览器或桌面应用的本地存储中。清除站点数据会删除记录。地图底图来自 OpenStreetMap，国家边界来自 `datasets/geo-countries`，一级行政区边界来自 geoBoundaries；打开地图时需要联网。

建议后续加入加密导入 / 导出备份、档案编辑与删除、地点搜索及自动获取坐标。使用者应自行遵守所在地法律并保护他人隐私。
