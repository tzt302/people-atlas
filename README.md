# 相遇志 · People Atlas

一个为个人使用设计的相遇人物分类与地图档案。数据默认保存在浏览器本地，不需要账号或后端服务。

现已提供 Windows 桌面安装版。软件每次启动都会检查 GitHub Release，发现新版本后自动下载，并在重启或退出时完成安装。

## 第一版功能

- 全球国家人数热力图：白色表示暂无记录，颜色越深表示人数越多
- 国家地理视图：基于 OpenStreetMap 标记到具体建筑坐标
- 分类视图：具体地点、国家、店类型、人物类型四个可展开标签子界面，支持组合筛选和排序
- 人物档案：照片、姓名、五种店类型（快餐、半、全、按摩、外卖）、人物类型、地理位置与简介
- 新建人物时可直接选择已有的国家、具体地点和人物类型标签，也可以输入新标签
- 人物预览卡片显示用户输入的简介；具体地点保存后显示为带定位图标的特殊标签
- 人物详情：支持按第一次、第二次、第三次等持续添加独立见面手记，保留日期与正文；提供中文与英文五星水平评分
- 全局地理 / 分类视图切换、响应式布局、浅色 / 深色主题
- 分类页顶部集中展示搜索、排序与四组标签筛选，并提供一键平滑回到顶部
- 浏览器 `localStorage` 本地持久化

## 本地运行

这是一个无构建步骤的静态网站。由于地图和 ES Modules 需要 HTTP，请不要直接双击 `index.html`。

```powershell
python -m http.server 4173
```

然后打开 <http://localhost:4173>。

### 桌面开发

```powershell
pnpm install
pnpm start
```

生成 Windows 安装程序：

```powershell
pnpm dist
```

## 数据与隐私

人物资料和上传照片保存在当前浏览器的本地存储中。清除站点数据会删除这些记录。地图底图来自 OpenStreetMap，国家边界来自 `datasets/geo-countries`；打开地图时需要联网。
